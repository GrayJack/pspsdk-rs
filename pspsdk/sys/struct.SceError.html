Type representing return errors from the PSP APIs, official or otherwise.

It’s valid range is (0x80000001, 0xFFFFFFFF].

pub const fn from_raw(raw: u32) -> Option<Self>

Create a new Error structure from a raw value.

This functions checks for the value of raw to be a in the range of possible SceError values used by the PSP OS and homebrews, returning an [None] otherwise. That means that this function allows the creation of custom error codes outside of the range used in by the PSP OS.

§Note

This type has as constants all the OS error codes. We encourage to use them when possible.
