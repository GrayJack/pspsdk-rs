Expand description

Flags representing digital controller button.

Each flag corresponds to a different button and can be used to extract button states from CtrlData and LatchData structures. Flags can be combined using bitwise OR operation to check for multiple key states at once.

§Note

The following buttons can only be read at a kernel-level: PadButtons::Home, PadButtons::WlanUp, PadButtons::Remote, PadButtons::VolumeUp, PadButtons::VolumeDown, PadButtons::Screen, PadButtons::Note, PadButtons::Disc, and PadButtons::MemoryStick
