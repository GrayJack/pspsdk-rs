Available on Play Station Portable only.
Expand description

Gets the currently set idle timer cancel movement threshold values for the analog stick.

§Parameters

  • unhold_threshold: A reference to receive the movement needed by the analog stick to reset the idle timer when HOLD mode is inactive.
  • hold_threshold: A reference to receive the movement needed by the analog stick to reset the idle timer when HOLD mode is active.

§Return Value

Ok value on success, error value otherwise.

§Firmware Version

This API was introduced on PSP firmware version 1.50.
