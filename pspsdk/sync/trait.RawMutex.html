Expand description

Define basic operations for a mutex.

A type that implements this can be used with the Mutex type to have a mutex that functions similarly as the Rust standard library mutex.

Required Methods§

Source

fn lock(&self)

Locks the mutex or panics if the lock is already held by the current thread.

Source

fn try_lock(&self) -> bool

Tries to acquire this mutex without blocking, returning true if the lock was successfull and false otherwise.

Source

unsafe fn unlock(&self)

Unlocks this mutex.

§Safety

This method may only be called if the mutex is held in the current context, i.e. it must be paired with a successful call to lock, try_lock, try_lock_for or try_lock_until.
