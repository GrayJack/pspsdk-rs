Expand description

Define basic operations for a ReadWrite Lock.

A type that implements this can be used with the RwLock type to have a lock that functions similarly as the Rust standard library rwlock.

§Safety

Releases an write lock.

§Safety

This method may only be called if an write lock is held in the current context.

Source

unsafe fn downgrade(&self)

Atomically downgrades an write lock into a read lock without allowing any thread to take an write lock in the meantime.

§Safety

This method may only be called if an write lock is held in the current context.
